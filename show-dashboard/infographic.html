What the run produced.

Each record below came from the demo. We read the input, create a SHA-256 hash, write it to Hedera, and check it through Mirror Node.

The short versionFour records. One workflow. Each sequence opens its public proof.
01 / INPUTReadMarket data, a document, or a payment.
02 / EVENTShapeTurn it into a stable event.
03 / HASHFingerprintCreate the SHA-256 digest.
04 / HCSWriteStore the digest on Hedera.
05 / CHECKCompareRead it back from Mirror Node.
Research, crypto risk, documents, and payments can use the same proof step.
